GitHub Pages 사용법
1. 기존 저장소의 index.html을 포함한 이전 웹 파일을 삭제하거나 교체합니다.
2. 이 폴더의 4개 파일을 저장소 최상위(root)에 업로드합니다.
3. Commit changes를 누릅니다.
4. 1~3분 후 사이트를 새로고침합니다.

중요
- 4개 파일의 이름을 바꾸지 마세요.
- 파일을 별도 폴더에 넣지 말고 README.md와 같은 최상위 위치에 올리세요.
- Google Sheet 공유는 '링크가 있는 모든 사용자 - 뷰어'여야 합니다.
- 시트 헤더: Day / 영단어 / 품사 / 뜻 / 사용

앞으로는 구글시트에 단어를 추가하고 사이트만 새로고침하면 됩니다.
